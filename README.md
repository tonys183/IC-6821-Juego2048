# IC-6821 — Diseño de Software

## Juego 2048

Implementación del juego 2048 en Java. El jugador desplaza las fichas del tablero y combina valores iguales para aumentar su puntuación y alcanzar la ficha 2048.

El proyecto organiza el tablero, las fichas y la interacción del juego mediante clases, aplicando programación orientada a objetos. Incluye código fuente, pruebas y configuración de Gradle.
